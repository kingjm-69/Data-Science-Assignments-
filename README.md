# Diabetes Prediction using Logistic Regression

## Project Overview

This project predicts whether a patient is likely to have diabetes using a Logistic Regression Machine Learning model.

## Features

- Data Preprocessing
- Outlier Analysis
- VIF Analysis
- Logistic Regression Model
- Model Evaluation
- Pickle Model Saving
- Streamlit Deployment

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Matplotlib
- Seaborn

## Files

- Logistic_Regression.ipynb
- app.py
- diabetes_model.pkl
- scaler.pkl
- diabetes.csv

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
